# Role-based dashboard update

- EMPLOYEE: personal request metrics and new request action.
- MANAGER: approval queue and company request metrics.
- PROCUREMENT_OFFICER: sourcing, suppliers, quotations and orders.
- ADMIN: company-wide overview.
- Sidebar links and direct routes restricted by role.
- Django remains the final authorization authority.
- No backend files changed.

Run `npm install`, `npm run build`, `npm run dev`.
